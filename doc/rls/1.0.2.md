# Release 1.0.2 - Changelog Summary

This release expands Vibe4Dock's browser-based workspace model and makes addon integration more declarative, reusable, and practical for day-to-day development. It introduces new optional tools and services, improves dashboard integration, and strengthens the underlying Compose and scaffolding workflow.

- **Browser Workspace Expansion**  
  Vibe4Dock now supports browser-accessible endpoints more generically, not just the built-in application and root shells.  
  Addons can now dock their own shells or web UIs directly into the dashboard with a more consistent user experience.

- **Declarative Addon Runtime Model**  
  Addons can now define dashboard endpoints, multiple Compose services, and scaffolded project files directly from JSON definitions.  
  This reduces special-case runtime logic and makes richer addons easier to build and maintain.

- **Generic Browser Shell Launching**  
  The web container now reads generated browser shell launcher definitions during startup and starts addon-provided ttyd sessions automatically.  
  This creates a reusable foundation for browser shells like Lazygit without hardcoded addon-specific startup logic.

- **Expanded Git and Browser Tooling**  
  Lazygit was added as a bundled Git tool, together with a dedicated Lazygit Shell addon.  
  New optional addons such as code-server and OneDev also broaden Vibe4Dock into a more complete browser-based development environment.

- **Database Workflow Improvements**  
  Adminer was added as an optional database addon with one-click logins for supported database services.  
  Database password fields are now handled more consistently as password inputs, improving safety and clarity in the configuration UI.

- **More Reliable Compose and Rebuild Handling**  
  Rebuild scripts now remove orphaned containers, and generated Docker overrides can merge multiple addon service definitions correctly.  
  This makes addon install, rename, and removal workflows more predictable as the stack becomes more modular.

- **Clearer Configuration Visibility**  
  Tool and addon summaries now show empty and disabled values explicitly instead of silently hiding them, while sensitive values remain masked.  
  The dashboard also reports protection status more consistently across built-in shells and addon-provided endpoints.

- **CLI and Documentation Polish**  
  The setup CLI now exposes its own version via `--version` / `-v` and shows the current version more clearly in setup and help output.  
  The English and German READMEs were updated for Vibe4Dock 1.0.2, including the new addon model, browser endpoints, and revised setup guidance.

**Compatibility**: Backward compatible. The new browser endpoints, tools, and addons are optional extensions on top of the existing workflow.
