# Release 1.0.3 - Changelog Summary

This release tightens Vibe4Dock's AI CLI integration by adopting the official native installers for the bundled tools and adding OpenCode as a first-class option. The result is a leaner, more reliable tool stack with fewer runtime dependencies and an installation path that stays aligned with what each upstream project actually recommends.

- **OpenCode CLI Added**  
  OpenCode CLI is now bundled under the AI CLI category as `170_opencode`.  
  It is installed via the official `curl -fsSL https://opencode.ai/install | bash` installer and persists its configuration under `~/.config/opencode`.

- **Native Installers for All Bundled AI CLIs**  
  GitHub Copilot CLI, Codex CLI, and Claude Code are no longer installed through `npm install -g`.  
  They now use the upstream-recommended curl installers (`gh.io/copilot-install`, `chatgpt.com/codex/install.sh`, `claude.ai/install.sh`), keeping the installation flow identical to a direct host install.

- **No Node.js Dependency for AI CLIs**  
  The `node` dependency was removed from Copilot CLI, Codex CLI, Claude Code, and OpenCode CLI.  
  All four tools now ship as standalone binaries, so projects that do not need Node.js for anything else no longer pay the cost of installing it just to satisfy an AI CLI requirement.

- **Cleaner Codex Integration**  
  The Codex installer is invoked with `CODEX_INSTALL_DIR=/usr/local/bin`, `CODEX_HOME=/home/application/.codex`, and `CODEX_NON_INTERACTIVE=1`, so the binary is placed on `PATH` directly, the install data lives inside the existing persistent mount, and the script does not try to modify shell config files.  
  A follow-up `chown` ensures the application user can write session data into the mounted config directory.

- **Consistent Symlink Pattern**  
  Copilot CLI, Claude Code, and OpenCode CLI all follow the same pattern: the upstream installer writes the binary into the application user's `~/.local/bin`, and a symlink in `/usr/local/bin` makes it available system-wide.  
  Uninstalls cleanly reverse the same steps.

- **Version Bump and Documentation**  
  `src/Cli.php`, `README.md`, and `readme/README.de.md` were updated to reflect the new 1.0.3 release.  
  The English and German READMEs list OpenCode CLI alongside the other AI CLIs.

**Compatibility**: Backward compatible. Existing AI CLI installations continue to work, and the new install/uninstall commands are idempotent and non-destructive for the persistent config mounts.
