# Release 1.0.9 - Changelog Summary

This release makes the developer chat run as Veronica out of the box: the Veronica addon generates an additional, visible opencode agent and the Chat addon preselects it by default.

- **Chat Runs as Veronica by Default (veronica-chat Agent)**
  The chat used to start with opencode's built-in `build` agent - a bare coding assistant with no idea it was part of Vibe4Dock. The Veronica addon now generates a third agent on container start, `veronica-chat`: the same Veronica persona (identity, style, project rules), but **visible** - `veronica` and `veronica-plan` stay hidden and remain exclusive to the Veronica UI. The chat addon preselects `veronica-chat` when no `OPENCODE_AGENT` is configured and the generated agent file exists in the shared opencode config mount, so every message sent from the chat runs as Veronica, including the exact identity answer.
  *Benefit: every chat answer is on-brand without any configuration.*

- **Safe Without The Veronica Addon**
  The chat addon checks for the generated `agent/veronica-chat.md` in the shared opencode config directory before applying the default. Projects that install the chat without the Veronica addon keep the previous behavior (no preselection) instead of pointing at a non-existing agent.
  *Benefit: the new default only applies where the persona actually exists.*

- **Persona Stays Multi-File And Extendable**
  Extra rules for the chat variant live in `persona/veronica-chat/*.md` (opencode config) - drop in additional rule files and restart the container; the agent file is re-assembled from the shared `persona/veronica` rules plus the `veronica-chat` extras on every start. The generated agent files (`agent/veronica*.md`) remain generated - do not edit them directly.
  *Benefit: one persona, two frontends, no duplicated rule maintenance.*

- **Opt-Out**
  Setting `OPENCODE_AGENT` (chat addon setting or environment) pins any other default agent - `build` restores the pre-1.0.9 behavior. The agent selector in the chat still lists `build`, `plan` and every visible custom agent, and a manually picked agent is remembered per browser.
  *Benefit: the new default is a default, not a lock-in.*

- **Version Bump and Documentation**
  `src/Cli.php` was bumped to 1.0.9, `README.md` and `readme/README.de.md` were updated (Veronica sections now describe the `veronica-chat` chat default), and `doc/rls/1.0.9.md` was added.

**Compatibility**: Backward compatible. Existing generated projects bake the addon `start.sh` scripts at generation time - reinstall the Veronica and Chat addons in the Tools UI (or regenerate the project) and restart the containers to pick up the new agent generation and chat default; new projects get both automatically. One behavioral change: the chat's default agent/persona (opt-out above). No new environment variables, no schema changes.
