# Release 1.0.0 – Initial Stable Release

This release introduces the first stable foundation of Vibe4Dock: a browser-accessible Docker development workspace with integrated AI CLI tooling, dynamic provisioning, persistent runtime configuration, and modular project setup.

* **Browser-based Development Workspace**
  Provides direct browser access to both application and root shell environments through integrated `ttyd` sessions.
  *Benefit: work on projects from desktop, laptop, tablet, or phone without depending on the local machine setup.*

* **Integrated AI CLI Tooling**
  Ships with support for modern AI developer tools such as GitHub Copilot CLI, Codex CLI, Claude Code, Cline CLI, Hermes CLI, and Junie CLI.
  *Benefit: centralized AI-assisted development workflows inside one consistent environment.*

* **Dynamic Tool Provisioning & Runtime Management**
  Tools can be installed, updated, switched, or removed through the management interface with automatic provisioning and override generation.
  *Benefit: flexible environments without maintaining oversized static Docker images.*

* **Persistent CLI Configuration & Runtime Data**
  Preserves caches, login sessions, tool configuration, and mounted runtime data across rebuilds.
  *Benefit: rebuild containers without losing developer state or CLI authentication.*

* **Modular JSON Configuration System**
  Introduces mergeable category, tool, and settings definitions through layered JSON configuration files.
  *Benefit: clean project-specific and team-wide customization without modifying the core system.*

* **Integrated Setup CLI**
  Includes interactive and non-interactive project generation directly from the bundled skeleton template system.
  *Benefit: fast onboarding and reproducible development environments.*

* **Multiple Database Backends**
  Supports MariaDB, MySQL, PostgreSQL, and Firebird environments during project setup.
  *Benefit: adaptable local development setups for different project requirements.*

* **Persistent Browser Shell Sessions**
  Application shell sessions run through `tmux` with separate root and application environments.
  *Benefit: continue working seamlessly across reconnects and devices.*

* **Dynamic Docker Volume & Provisioning Generation**
  Automatically generates provisioning scripts and Docker override configurations for enabled tools.
  *Benefit: persistent tooling and runtime extensions without manual Compose editing.*

* **Development-focused Architecture**
  Introduces a dedicated tools service for runtime management, provisioning orchestration, and environment monitoring.
  *Benefit: centralized environment control with simplified operational workflows.*

**Compatibility:** Initial stable release targeting Docker-based development environments with PHP CLI 8+ and Docker Compose.
