## Release 1.0.1 – Changelog Summary

This release focuses on making Vibe4Dock's tool and addon workflow more reliable, modular, and easier to use in real projects. It improves installation behavior, version detection, Git configuration handling, and the overall flexibility of the generated environment.

- **Tooling Workflow Cleanup**  
  Vibe4Dock now relies more consistently on JSON-driven tool and addon definitions instead of hardcoded setup logic.  
  This makes the environment easier to extend and keeps configuration more predictable.

- **Standalone Git Configuration Tool**  
  Git Config was migrated from legacy settings handling into its own dedicated tool in the new Git category.  
  Users now get a cleaner and more consistent workflow for managing Git identity inside the environment.

- **More Reliable Tool Installation Paths**  
  Several installation issues were fixed so tools like Laravel CLI and Junie are installed into locations that work correctly from the application shell.  
  This reduces confusing "installed but not usable" situations.

- **Startup Permission Fixes**  
  Tool mount permissions are now corrected before startup-time restores run.  
  This prevents failures when bind-mounted tool directories need to be reused across container restarts.

- **Normalized Version Detection**  
  Tool and addon definitions now support centralized version regex handling, and displayed versions are normalized in the UI.  
  Users get more accurate and consistent version reporting across installed components.

- **Expanded Tool and Addon Foundations**  
  New skeleton definitions were added for additional CLI tools, runtime environments, and database addons.  
  This broadens the project's extensibility and prepares the platform for more optional components.

- **Safer Uninstall and Cleanup Behavior**  
  Uninstall logic was improved, including idempotent Symfony CLI removal and correct empty `composer.json` handling after package cleanup.  
  This avoids misleading errors and keeps generated project files valid.

- **Documentation and Setup Improvements**  
  The English and German READMEs were updated for Vibe4Dock 1.0.1, including clone instructions, workflow clarifications, and release documentation.  
  New users get clearer setup guidance, and existing users get better visibility into the revised tool/addon model.

**Compatibility**: Backward compatible, with legacy Git configuration environments explicitly considered during the migration.
